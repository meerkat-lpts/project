# Software

Open-source tools used in this project.

## Searching for pulses

| Tool | Used for |
|---|---|
| [TransientX](https://github.com/ypmen/TransientX) | Single-pulse search of the high-time-resolution (PTUSE) data |
| [PulsarX](https://github.com/ypmen/PulsarX) | Folding templates and data handling for TransientX |

## Imaging and dynamic spectra

| Tool | Used for |
|---|---|
| [CASA](https://casa.nrao.edu/) | Calibration and image-plane fitting |
| [PolKAT](https://github.com/AKHughes1994/polkat) | Full-polarisation calibration and snapshot imaging of MeerKAT data |
| [WSClean](https://gitlab.com/aroffringa/wsclean) | Imaging, including on-pulse time windows |
| [dstools](https://github.com/joshoewahp/dstools) | Dynamic spectra from visibilities |

## Polarimetry and timing

| Tool | Used for |
|---|---|
| [PSRCHIVE](https://psrchive.sourceforge.net/) | Calibration and polarimetry of PTUSE data |
| [RM-Tools](https://github.com/CIRADA-Tools/RM-Tools) | Rotation-measure synthesis |
| [spinifex](https://pypi.org/project/spinifex/) | Ionospheric Faraday rotation |
| [DM_phase](https://github.com/danielemichilli/DM_phase) | Dispersion measures of bright pulses |
| [PINT](https://github.com/nanograv/PINT) | Timing analysis with the `.tim` files on the [TOA page](toas.md) |
